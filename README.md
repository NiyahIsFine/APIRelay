# APIRelay

APIRelay is a Windows desktop app for forwarding AI API requests, managing providers and models, and tracking usage in one place.

## Features

- **API relay:** Forward and convert between Chat Completions, Responses, and Messages, with streaming and tool-call support.
- **Provider and model management:** Configure upstream endpoints and API keys, discover models, and customize model settings and pricing.
- **Client integration:** Manage Claude Code and Codex configurations with automatic backup and restoration.
- **Usage tracking:** View request history, token usage, cache statistics, estimated costs, and trends.
- **Diagnostics:** Inspect runtime logs and per-request protocol traces.
- **Desktop experience:** Light and dark themes, English and Chinese interfaces, system tray support, and a floating usage window.
